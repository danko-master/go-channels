## Структура канала

`hchan - в исходном коде Go она находится в файле src/runtime/chan.go`

```
type hchan struct {
	qcount   uint           // Всего элементов в буфере. Для небуферизованного ВСЕГДА = 0
	dataqsiz uint           // Размер буфера. Для небуферизованного ВСЕГДА = 0
	buf      unsafe.Pointer // Указатель на массив элементов буфера. Тут он равен nil
	elemsize uint16         // Размер одного элемента в байтах (например, 8 для int64)
	closed   uint32         // Флаг закрытия канала (0 — открыт, 1 — закрыт)
	elemtype *_type        // Информация о типе данных (нужно для работы GC)
	sendx    uint           // Индекс записи в буфер. Не используется (всегда 0)
	recvx    uint           // Индекс чтения из буфера. Не используется (всегда 0)

	// ОЧЕРЕДИ ОЖИДАНИЯ — Самая важная часть небуферизованного канала
	recvq    waitq          // Список ЗАБЛОКИРОВАННЫХ горутин, которые ждут ЧТЕНИЯ
	sendq    waitq          // Список ЗАБЛОКИРОВАННЫХ горутин, которые ждут ЗАПИСИ

	lock     mutex          // Мьютекс для защиты всех полей структуры при обращении из разных потоков
}
```

## Небуферизованный канал

Вся логика работы небуферизованного канала держится на трех полях: recvq, sendq и lock
